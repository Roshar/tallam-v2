# Импорт подписок школ

JSON-файлы с реальными школами не коммитятся в git.

Формат:

```json
[
  {
    "email": "school@example.ru",
    "schoolName": "Название школы",
    "contactPhone": "+7 900 000-00-00",
    "startsOn": "2025-09-01",
    "endsOn": "2026-09-01",
    "sourceLabel": "Договор 2025",
    "note": "Необязательное примечание"
  }
]
```

`endsOn` можно не указывать — импортёр рассчитает окончание через один год.
Школа сопоставляется сначала по email кабинета, затем по точному названию.
Если для одной школы в файле несколько почти одинаковых строк, используется
строка с наиболее поздней датой начала.

Запуск:

```bash
npm run db:import-subscriptions -- database/subscriptions/subscriptions.json
```
